# Contributing

Currently a solo/family project — this file exists so it's ready if the
template gets shared or forked later.

## Ground rules
- Features go through the repository interface — see [CLAUDE.md](CLAUDE.md) and
  `.claude/skills/sheets-backed-feature/SKILL.md`.
- Ship a phase end-to-end before starting the next (see Notion Build Tasks).
- No multi-property or payment-gateway code — out of scope by design, not by
  oversight.

## Commit style
Conventional commits (`feat:`, `fix:`, `chore:`) — matches existing history.
